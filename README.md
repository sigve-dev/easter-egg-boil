# easter-egg-boil

A fun little project I worked on over the easter season 2025. 
Written in TypeScript, React, and CSS.
An animated timer for perfectly soft- or hard-boiled eggs.

### Features
- Soft- and hard-boil timers
- Egg size selection (small, medium, large)
- Animated chicken visuals 
- Dark mode toggle 
- Alarm when your egg is done!
